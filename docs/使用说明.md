# AgenticArXiv 使用说明

面向使用者的完整指南：从安装、配置到日常使用与排错。系统为**单用户部署**，不需要注册或登录。

---

## 1. 系统能做什么

| 功能 | 说明 |
|---|---|
| 对话式检索 | 用自然语言描述需求（中英文均可），自动转成学术检索词，在 OpenAlex 全学科库中查找并过滤 |
| 最新 arXiv | 按计算机子领域 + 时间窗口获取最新论文，支持关键词包含/排除 |
| 论文管理 | 会话论文列表、订阅论文、标签、收藏、批注 |
| PDF 下载 | 支持 arXiv 与 DOI/OpenAlex 来源；也可上传本地 PDF |
| 全文翻译 | 调用 pdf2zh 输出中文单语版（可选双语），异步执行、进度可见 |
| 全文问答（RAG） | 基于 PDF 全文回答问题，给出引用页码；可结合划词与批注 |
| 结构化摘要 | 生成研究背景 + 主要创新点，可指定关注角度 |
| 多篇对比 | 2–10 篇论文按方法论/性能/创新点等维度对比并给出推荐 |
| 定时订阅 | 按关键词与分类定期检索，结果自动进入论文区 |
| 运行日志 | 每次对话的思考、工具调用、耗时与 token 用量 |

技术栈：FastAPI + Vue 3 + MySQL 8。默认后端 `:8000`，前端 `:5173`。

---

## 2. 环境要求

- Python **3.10 – 3.13**（推荐 3.11 / 3.13；3.13 使用 NumPy 2，安装脚本会自动适配）
- Node.js **22.13+**（含 npm；PDF 预览依赖的 pdfjs-dist 要求 22.13+，Node 20 会提示 EBADENGINE）
- MySQL **8.0+**
- 能访问：arXiv、OpenAlex、以及一个 OpenAI 兼容的 LLM 接口
- 磁盘：代码与依赖约 1–2 GB；论文 PDF/译文按篇计（每篇约 1–10 MB）

## 3. 安装

### 3.1 准备数据库

```sql
CREATE DATABASE agentic_arxiv CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'arxiv'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON agentic_arxiv.* TO 'arxiv'@'localhost';
FLUSH PRIVILEGES;
```

表结构不需要手工创建：后端首次启动时 `init_db()` 会自动建表。

### 3.2 配置 `AgenticArxiv/.env`

在 `AgenticArxiv/` 目录下创建 `.env`（可从 `.env.example` 复制）：

```ini
# 数据库
MYSQL_URI=mysql+pymysql://arxiv:your_password@127.0.0.1:3306/agentic_arxiv?charset=utf8mb4

# LLM（OpenAI 兼容接口）
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=sk-xxxx
MODEL=deepseek-chat

# 可选：翻译
PDF2ZH_SERVICE=openai:deepseek-chat
PDF2ZH_THREADS=4

# 可选：Agent 类型（regex 默认）
AGENT_TYPE=regex
```

> `LLM_API_KEY` 只保存在本机数据库/环境变量中，前端只显示后 4 位。

### 3.3 安装依赖

```bash
python scripts/bootstrap.py            # 自动创建 .venv 并安装 Python / npm 依赖
# 或使用锁定版本（推荐部署时使用）
python scripts/bootstrap.py --locked
```

脚本会自动区分 Windows（`.venv\Scripts`）与 Linux/macOS（`.venv/bin`）。
Linux 上若没有 `python` 命令，请替换为 `python3`。

> `--locked` 的版本锁是在 **Python 3.13** 上导出的。若你的 Python 是 3.11/3.12，
> 脚本会自动跳过 `audioop-lts` 等仅适用于 3.13 的包；如果仍出现版本冲突，
> 去掉 `--locked` 用默认方式安装即可（`pdf2zh` 已在 requirements 中固定为 1.7.9）。
>
> 安装完成后脚本会自动修补 pdf2zh 1.7.9 的 NumPy 2 兼容问题（`np.fromstring` → `np.frombuffer`）。

> **项目放在 U 盘上时**：Windows 会禁止在移动盘里创建并执行 venv 的 `python.exe`
> （报 `WinError 5 拒绝访问`）。请把虚拟环境放到本机磁盘：
>
> ```bash
> python scripts/bootstrap.py --venv C:\venvs\agentic_arxiv
> ```
>
> 脚本会记住这个路径（写入 `.venv_path`），之后 `scripts/service.py` 会自动使用它。

### 3.4 Windows 本机快速安装（推荐流程）

```powershell
# 1) 确认环境
python --version     # 3.10 - 3.13
node -v              # >= 22.13
mysql --version      # 8.0+

# 2) 建库（用 root 登录 MySQL 后执行 3.1 的 SQL）

# 3) 安装依赖（venv 放本机磁盘，代码可以放 U 盘）
cd E:\agentic_new_for_usb
python scripts/bootstrap.py --venv C:\venvs\agentic_arxiv

# 4) 按 3.2 配置 AgenticArxiv\.env（Windows 上不要写 /home/... 这类 Linux 路径）

# 5) 启动并检查
python scripts/service.py start
python scripts/service.py status
```

浏览器打开 `http://127.0.0.1:5173`。同一局域网的其他电脑访问
`http://<本机IP>:5173`（Windows 防火墙需放行 5173 与 8000）。

> pip 下载慢时可以先设置镜像：
> `python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`

> 前端依赖已经装过时，可加 `--skip-frontend` 跳过 `npm install`。

## 4. 启动与停止

```bash
python scripts/service.py start     # 启动后端 + 前端
python scripts/service.py status    # 查看状态（pid / http 是否正常）
python scripts/service.py logs -n 100 --follow   # 查看日志
python scripts/service.py stop      # 停止
```

Linux/macOS 也可以使用：

```bash
make install     # = python3 scripts/bootstrap.py
make             # = python3 scripts/service.py start
make status
make stop
```

启动后访问：

- 前端：`http://<服务器IP>:5173`
- 后端文档：`http://<服务器IP>:8000/docs`

修改端口：

```bash
python scripts/service.py start --backend-port 8010 --frontend-port 5180
```

## 5. 首次配置（Web 界面）

1. 打开前端页面，进入左侧 **设置**。
2. **LLM 接入**：填写 Base URL、API Key、模型名，点“测试连接”，成功后保存。
   - 常见组合：DeepSeek `https://api.deepseek.com` + `deepseek-chat`；
     OpenAI `https://api.openai.com` + `gpt-4o-mini`；
     通义 `https://dashscope.aliyuncs.com/compatible-mode` + `qwen-plus`。
3. **翻译服务**：选择 `openai`（复用上面的 Key）或 `deepl`（需填 DeepL Key）。
4. 保存后即可在 **对话** 页开始使用。

> 配置是系统级的，保存在数据库 `app_settings` 表中。

## 6. 日常使用

### 6.1 检索论文

在 **对话** 页直接描述需求，例如：

- 「帮我找 2025-2026 年用神经网络预测软组织形变的论文，最多 5 篇」
- 「搜索医学图像分割领域的论文」
- 「搜索使用改进的 YOLO 进行小目标检测的论文」

Agent 会调用检索工具，把结果写入 **论文** 页；答复中会给出标题、核心思路与趋势总结。
同一次请求只保留第一次检索结果，不会因为模型多次核验而重复堆叠。

### 6.2 论文页

每篇论文可以：

- **预览**原始 PDF / 中文译文
- **下载**（arXiv、DOI/OpenAlex；也可从本地上传 PDF）
- **翻译**（异步，进度条实时更新）
- **总结**（背景 + 创新点）
- **加入对比**
- 打 **标签**、**收藏**、写 **批注**

### 6.3 全文问答（RAG）

在 **RAG** 页选择已下载的论文，直接提问，例如：

- 「这篇论文用了哪些数据集？」
- 「实验结果相对 baseline 提升了多少？」

回答会附引用页码；也可以在 PDF 中划选一段文字后就选中内容提问。

### 6.4 多篇对比

在 **对比** 页选择 2–10 篇论文，系统按方法论、性能、创新点等维度分析并给出推荐。

### 6.5 定时订阅

在 **订阅** 页新建订阅：

- 名称、分类（如 CV / LG / CL，留空表示全部 CS）
- 关键词（支持中文，系统会自动翻成英文检索词）
- 匹配模式：`any`（任一命中）/ `all`（全部命中）
- 天数、每次数量、自动间隔（分钟）

保存后可点 **立即执行**；结果会带 `订阅` 标签进入论文区。

## 7. 数据与目录

```
AgenticArxiv/output/
├── pdf_raw/                 # 原始 PDF
├── pdf_translated/          # 中文译文（*-mono.pdf）
├── pdf_translated_log/      # pdf2zh 运行日志
├── paper_summaries.json     # 结构化摘要缓存
├── tmp/                     # 翻译临时目录
└── log.txt                  # 运行日志
```

数据库主要表：

- `sessions` / `session_papers`：会话与论文列表
- `pdf_assets` / `translate_assets`：PDF 与译文缓存
- `paper_annotations` / `paper_tags` / `paper_bookmarks`：批注、标签、收藏
- `paper_comparisons` / `comparison_dimensions`：论文对比
- `subscriptions` / `subscription_runs`：订阅与执行记录
- `paper_chunks`：RAG 切片索引
- `chat_logs` / `agent_steps`：对话与 Agent 步骤日志
- `app_settings`：LLM 与翻译配置

备份建议（数据库 + 文件一起）：

```bash
mysqldump -u root -p agentic_arxiv > backup_$(date +%F).sql
tar -czf output_$(date +%F).tgz AgenticArxiv/output/pdf_raw AgenticArxiv/output/pdf_translated
```

## 8. 常见问题

**Q1：对话报“LLM 调用失败 / 401”**
检查设置页的 Base URL、API Key、模型名；点“测试连接”确认。Base URL 带不带 `/v1` 都可以。

**Q2：翻译失败，提示找不到 pdf2zh**
用 `python scripts/service.py start` 启动（已自动把 venv 的 bin 目录加入 PATH）；
或设置环境变量 `PDF2ZH_BIN` 指向 pdf2zh 可执行文件后重启。

**Q2b：翻译报 `ImportError: cannot import name 'TextTranslateRequest'`**
这是 pdf2zh 1.9.x 与新版 `tencentcloud-sdk-python-tmt` 的不兼容（1.9.x 引入的腾讯云依赖在新版 SDK 中删了该类）。
本项目固定使用 `pdf2zh==1.7.9`，执行：

```bash
python -m pip install "pdf2zh==1.7.9"
```

然后重启服务即可。

**Q2c：`--locked` 安装报 `Could not find a version that satisfies the requirement audioop-lts==0.2.2`**
`audioop-lts` 是 Python 3.13 专用包，而锁文件是在 3.13 上导出的。
新版 `bootstrap.py` 会自动跳过它；如果你的脚本还是旧版，直接去掉 `--locked`：

```bash
python scripts/bootstrap.py
```

**Q2d：翻译报 `ValueError: The binary mode of fromstring is removed`**
NumPy 2 移除了 `np.fromstring`，而 pdf2zh 1.7.9 仍在用它。两种解决方式（任选其一）：

- 重新运行 `python scripts/bootstrap.py`（会自动修补 pdf2zh，并给 Python <3.13 装 NumPy 1.x）
- 手动降级：`python -m pip install "numpy<2"`

**Q3：翻译很慢或卡在某个百分比**
首次运行需要下载 DocLayout-YOLO 模型；翻译速度取决于 LLM 接口。进度条会按时间推进，
若长时间不动请查看 `output/log.txt` 与 `output/pdf_translated_log/`。

**Q4：检索结果为 0**
尝试减少关键词、放宽年份、降低相关度阈值，或改用英文关键词。
OpenAlex 偶尔会 429/503，稍后重试即可。

**Q5：端口被占用**
`python scripts/service.py status` 查看；先 `stop`，或换端口启动。

**Q6：页面空白 / 请求失败**
确认后端 `:8000` 已启动；若前端与后端不在同一台机器，请把前端 `VITE_API_BASE` 指向后端地址。

**Q7：在 U 盘上运行 `bootstrap.py` 报 `WinError 5 拒绝访问`**
Windows 不允许在移动盘上创建/执行虚拟环境的解释器。用
`python scripts/bootstrap.py --venv C:\venvs\agentic_arxiv` 把 venv 放到本机磁盘即可，
代码与数据仍可留在 U 盘。

**Q8：安全性**
本系统是单用户版本，**没有登录与鉴权**。请只在内网使用；如需公网访问，建议在前面加
Nginx + Basic Auth 或仅通过 SSH 隧道访问。

**Q9：前端安装时出现 `EBADENGINE`（pdfjs-dist 要求 Node >=22.13）**
这是警告不是失败，Node 20 下通常仍能运行；但建议升级到 Node 22 LTS 后重新 `npm install`。

**Q10：第一次打开设置页报 500，日志里是 `Duplicate entry '1' for key 'PRIMARY'`**
旧版本首次并发初始化 `app_settings` 的竞态，已修复。更新代码后重启即可；
数据库里那一行已经存在，不会再触发。

## 9. 升级

```bash
git pull
python scripts/bootstrap.py            # 依赖有变化时（Python 3.13 可用 --locked）
python scripts/service.py stop && python scripts/service.py start
```

升级前建议先备份数据库与 `output/` 目录。

> 如果依赖变动较大（例如 python / node 大版本升级），建议直接重建 venv：
> 删除 `.venv`（或 `--venv` 指定的目录）后重新执行 `bootstrap.py`。
